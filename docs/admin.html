상품 태그 한 번으로 등록하세요.

쿠팡파트너스의 ‘블로그용 태그’를 붙여넣으면 상품명·배너·구매 링크를 읽습니다. 가격을 모르면 입력하지 않아도 됩니다.

이 화면은 저장 서버가 없는 등록 도구입니다. 내려받은 파일을 GitHub의 data/manual_items.json에 올린 후 ‘특가 갱신’을 실행해야 공개 홈페이지에 반영됩니다. 새로고침 전에 파일을 내려받으세요.

입력블로그용 태그 붙여넣기

HTML은 실행하지 않습니다. 허용 주소의 링크·이미지와 상품명만 읽습니다.

반자동 가격 입력 · 페이지 내용 붙여넣기

같은 상품·옵션의 가격 부분을 복사해 붙여넣으세요. 후보를 추출한 뒤 판매가와 정가를 직접 지정합니다. 단위가격·쿠폰·회원가가 섞일 수 있어 자동 확정하지 않습니다.

코드를 붙여넣은 뒤 ‘정보 읽기’를 누르세요.

확인등록될 상품 미리보기

1MB 이하 원본 이미지를 선택하면 파일 안에 포함되어 외부 CDN 없이 표시됩니다. 삼다수 연습 배너는 이미 포함되어 있습니다.

상품을 읽으면 이곳에 배너와 상품명이 표시됩니다. 이미지는 세로 비율을 유지합니다.

이 미리보기는 등록 도구용입니다. 득템 홈페이지에서는 수정된 build.py가 같은 정보를 카드로 표시합니다. 가격·재고 자동 조회는 하지 않습니다.

저장등록 목록 0건

기존 목록을 먼저 불러오세요. 불러온 항목에 새 상품을 합쳐 내려받습니다. 상품이 없는 빈 목록도 저장할 수 있습니다.

기존 파일을 불러오지 않았습니다. 현재 목록이 비어 있는지 확인하세요. 빈 파일로 교체하면 기존 수동 상품이 사라집니다.

    GitHub에 반영하는 방법
    1. 목록을 확인하고 manual_items.json 내려받기를 누릅니다.
    2. 저장소의 data 폴더에서 Add file → Upload files로 내려받은 파일을 올립니다. 파일명은 manual_items.json이어야 합니다.
    3. Commit changes로 저장합니다.
    4. Actions → 특가 갱신 → Run workflow를 실행합니다.
    5. 초록색 성공 표시 이후 공개 홈페이지를 새로고침합니다.

    이미지는 미리보기를 표시할 때 쿠팡 CDN에서 불러옵니다. 선택한 원본 이미지도 JSON에 포함됩니다. 입력한 HTML·등록 목록은 서버로 전송하지 않으며 브라우저 메모리에만 유지합니다. API 키·토큰·비밀번호는 입력하지 마세요. 외부 파일도 허용 주소와 형식을 검사한 뒤 불러옵니다.
