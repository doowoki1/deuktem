제휴 API 수집

골드박스 1콜 + 키워드 검색 N콜. HMAC 서명으로 인증하고, 실행마다 예산을 기록해 한도를 넘지 않습니다.

GET /products/goldbox
STEP 02

정규화 · 중복 제거

상품ID 기준으로 합치고, 48시간 동안 다시 보이지 않은 상품은 자동으로 내립니다.

dedupe by productId
STEP 03

가격 이력 계산

매 수집의 가격을 쌓아 최저·최고를 뽑고, 그 차이를 할인율로 표시합니다. 정가를 주지 않는 API의 빈칸을 이력으로 메웁니다.

history → drop%
STEP 04

정적 빌드 · 배포

HTML을 미리 렌더링해 GitHub Pages로 배포. 서버·DB 없이 CDN만으로 돌아갑니다.

python build.py → /docs
